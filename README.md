# 司辰手记

本地网页版《司辰之书》上树计划与进度记录工具。技术栈为 React、TypeScript、Vite，记录通过 IndexedDB 保存在当前浏览器。

## 本次迁移与百科

主项目已迁入 `D:\项目\sczs\boh-web`，旧 `web` 目录保留作备份。上级目录的启动入口已指向本项目。访问地址、IndexedDB 名称和备份格式保持不变；同一浏览器使用原地址可继续读取原记录。

侧栏“资料百科”收录 600 条资料，支持名称／材料／获取方式搜索、分类、准则、分支筛选。详情提供原表来源、关联资料与 Wiki 检索；技能和配方可以直接打开对应上树记录。闰识剧透默认隐藏。百科浏览不修改进度。

运行 `python scripts/import_encyclopedia.py` 可从原 Excel 重新生成百科数据（需 openpyxl）。数据范围、原表差异和授权见 [DATA_SOURCES.md](DATA_SOURCES.md)。百科为本地资料快照，不是完整实时 Wiki。

## 使用

在此目录执行 `npm install`（首次），然后执行 `npm run dev`，访问 http://127.0.0.1:5173 。也可以双击项目根目录的“启动司辰手记.cmd”。固定使用该地址，避免浏览器把不同地址视为不同存档。

- 搜索技能并记录实际等级，点击档位预览计划互换。
- 交换会检查两项技能各自支持的分支；已上树位置锁定。
- 等级不足可调整未来计划，但不能记录已上树。
- 在游戏中确认槽位解锁后勾选对应槽位，再记录上树。
- “已调谐”表示已经用此技能完成一次魂质进阶，以红字显示。
- “原始规划”是 Excel 的只读对照，修改的是当前计划。
- 自动保存每次修改，支持撤销最近 30 次操作（本次打开期间）和 JSON 导入导出。

浏览器数据不是文件备份，清理浏览器数据前请导出。初始等级均为“未记录”，不推断玩家存档。槽位解锁手动记录，不自动计算树上捷径或工作台适用性。技能备注也会自动保存。

## 验证

`npm test` 检查交换、跨分支兼容性、上树锁定、等级与解锁前提、备份校验。`npm run build` 类型检查并生成可静态托管的 dist 文件夹。
